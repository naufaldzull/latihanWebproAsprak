# Latihan Webpro — Asprak

Struktur folder untuk latihan soal praktikum.

## soal2-crud-film
Website CRUD data film bioskop (Laravel **atau** Nest.js, database MySQL **atau** PostgreSQL).

Properti data film: `id`, `judul`, `durasi` (integer), `deskripsi`.

Wajib: Create (tambah film), Read (daftar film), Update (ubah film), Delete (hapus film).

Struktur di dalamnya mengikuti pola MVC (controllers, models, migrations, views, routes).
